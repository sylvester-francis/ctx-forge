Every morning for the last three weeks, I've opened Claude Code and re-explained my codebase to it. The TLS decision. The auth middleware. Why we're still on tonic 0.10.

I got tired of being my AI's short-term memory. So I built ctxforge.

ctxforge is an open-source Rust CLI that does two things:

1/ A TUI that lets you assemble perfect context for your agent in 10 seconds, with a live token gauge so you can SEE what you're spending.

2/ A one-command MCP integration that gives Claude Code persistent memory across sessions. It writes notes to itself, and reads them back next time.

ctxforge implements the four strategies of context engineering — Write, Select, Compress, Isolate — as a single Unix tool. Zero cloud, zero API keys, AGPL-3.0 licensed.

Install: cargo install ctxforge

Built on nights and weekends. Would mean a lot if you starred it.
