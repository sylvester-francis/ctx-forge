**Post 4 — The four pillars**

ctxforge implements four strategies of context engineering:

Write → persistent notes across sessions
Select → add files, line ranges, specific functions
Compress → see token costs before you send
Isolate → profiles keep work streams separate

**Post 5 — The install**

No cloud. No API keys. No database. Single binary. Runs on your machine. Everything in .ctxforge/ on disk.
